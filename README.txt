HOW TO ADD A NEW CERTIFICATE:
1. Put the certificate image inside the images/ folder (e.g. images/cert3.jpg)
2. Open index.html, find the "certGrid" section under id="certificates"
3. Copy one whole <div class="certCard">...</div> block and paste it
4. Update the image src, alt text, title (h3) and description (p)
The design/style will automatically match the existing certificate cards.
